Ship JavaScript and Dart fixes to installed apps without a store release, from a server you run yourself.

| Repository | What it is |
|---|---|
| [patchkite](https://github.com/patchkite/patchkite) | Server and web dashboard |
| [cli](https://github.com/patchkite/cli) | Command-line interface (`@patchkite/cli`) |
| [react-native](https://github.com/patchkite/react-native) | React Native SDK (`@patchkite/react-native`) |
| [flutter](https://github.com/patchkite/flutter) | Flutter SDK (`patchkite` on pub.dev) |
| [docs](https://github.com/patchkite/docs) | Documentation source |
